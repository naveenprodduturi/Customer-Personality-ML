# Experiment 3 - Git-Based Version Control and Collaborative ML Workflow

## Objective

The objective of Experiment 3 is to implement Git-based version control and collaborative development workflows for the machine learning project.

The workflow includes repository management, branches, commits, merging, rollback, revert, and version traceability.

## Branching

A separate branch named experiment-3 was created for Experiment 3 development.

This allows Experiment 3 changes to be developed independently from the main branch.

## Version Traceability

Git tracks changes to:

- Dataset files
- Preprocessing scripts
- Training scripts
- Evaluation scripts
- ML models
- Experiment outputs
- Pipeline scripts
- Documentation

## Merge Workflow

Changes developed on the experiment-3 branch will be committed and then merged into the main branch.

## Rollback and Revert

Git history can be used to identify previous project versions.

A previous commit can be restored when necessary, while a revert commit can safely undo a previous change without deleting the complete project history.

## Reproducibility

Git commits provide a traceable history of project development.

Each major project stage can be associated with a specific commit, allowing the project to be reproduced from a known version.
